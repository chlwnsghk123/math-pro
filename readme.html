Math Pro — 오답노트 생성기

틀린 문제만 골라 오답노트를 만들고, 가로 A4 인쇄용 PDF로 저장하세요. 이미지 기반 문제 + KaTeX로 조판된 정답지가 함께 출력됩니다.

1. 3단계로 시작하기

  1. 문제 담기

    학년 탭(7~12)에서 문제를 클릭해 장바구니에 담거나, 상단 검색창에 9-30처럼 입력해 바로 추가합니다.

  2. 오답노트 생성

    장바구니에서 오답노트 생성을 누르고 제목·이름·날짜를 입력하면 노트가 저장됩니다. 장바구니는 자동으로 비워져요.

  3. 인쇄 / PDF

    상단의 내 오답노트에서 노트를 열고 인쇄 / PDF를 누르세요. 브라우저 인쇄 창에서 PDF 저장 또는 실제 인쇄가 가능합니다.

2. 화면 구성

메인 화면

좌측은 선택한 학년의 문제 그리드, 우측은 장바구니 사이드바입니다. 모바일에서는 사이드바 대신 하단 바텀시트가 뜹니다.

  • 학년 탭 — 07~12학년. 탭마다 현재 등록된 문제 수가 함께 표시됩니다.
  • 검색창 — 문제 번호로 즉시 추가. 자동완성 지원.
  • 장바구니 — 담은 순서와 무관하게 항상 학년·번호 순으로 정렬됩니다.
  • 내 오답노트 (N) — 저장한 오답노트 목록으로 이동.

오답노트 미리보기

가로 A4 (297×210mm) 한 페이지를 2×2 사분면으로 나눠 한 사분면당 한 문제씩 배치합니다. 단원이 바뀌면 자동으로 새 페이지로 넘어가요.

정답지 (마지막 페이지)

전체 문항의 답을 2단으로 단원별 그룹화해서 모아둡니다. 번호는 교재 그대로 (9-15의 답은 15.로) 표시돼요.

3. 어떤 데이터가 어디 저장되나요?

장바구니 이번 세션 동안만 유지. 새로고침하면 비워집니다.
저장된 오답노트 브라우저 localStorage에 저장됩니다 (math-pro:notebooks-v1). 새로고침해도 유지되고, 같은 브라우저·기기에서 다시 열 수 있어요.
제목·이름 기본값 마지막에 입력한 값이 다음 모달의 기본값으로 채워집니다. 날짜는 매번 오늘로 초기화돼요.
문제 이미지 GitHub 저장소의 main 브랜치 images/ 폴더에서 직접 불러옵니다. 앱 자체에 내장되어 있지 않아 추가 업로드가 반영되려면 main에 푸시되어 있어야 해요.
PDF 파일 브라우저의 "PDF로 저장" 기능을 사용합니다. 파일명은 제목-이름-날짜.pdf로 자동 채워져요 (이름이 비어있어도 OK).

4. 인쇄 / PDF 저장 팁

"PDF 저장" 버튼은 브라우저의 시스템 인쇄 창을 띄웁니다. 거기서 PDF로 저장하거나 실제 프린터로 출력할 수 있어요.

  • 용지 — A4, 가로(Landscape), 여백 "없음"으로 설정하세요.
  • 대상 — "PDF로 저장(Save as PDF)"을 선택하면 파일이 다운로드됩니다.
  • 머리글·바닥글 — 인쇄 대화상자의 "머리글/바닥글" 체크박스를 해제하면 브라우저가 추가하는 URL·날짜가 사라지고 앱의 푸터만 남습니다.
  • 배경 그래픽 — 일부 브라우저는 기본 OFF인데, 이 앱은 배경 색이 거의 없어 영향을 받지 않습니다.
💡 미리보기 화면에 보이는 모습이 그대로 출력됩니다. KaTeX 수식과 얇은 선이 캡쳐 단계에서 깨지지 않도록 브라우저 네이티브 인쇄를 사용해요.

5. FAQ

새로고침하면 담아둔 문제가 사라져요

맞아요. 의도된 동작입니다. 장바구니는 "이번 세션의 임시 작업대"라서 새로고침하면 비워집니다. 보존하려면 오답노트 생성으로 스냅샷을 만들어두세요 — 그건 영구 저장됩니다.

이미지가 "이미지 로드 실패"라고 떠요

GitHub 저장소의 images/<학년>/<번호>.png가 아직 업로드되지 않았을 가능성이 큽니다. 학년 폴더는 두 자리 (07, 08, …), 파일은 세 자리 (001.png) 형식이에요.

오답노트의 제목·이름·날짜를 나중에 바꿀 수 있나요?

네. 내 오답노트에서 해당 오답노트를 열면 상단 입력란에서 바로 수정 가능합니다. 수정은 자동 저장돼요. 단, 담긴 문제 목록은 생성 시점에 확정되어 변경할 수 없어요 — 새 오답노트를 만드세요.

오답노트는 어떤 기기에서 볼 수 있나요?

저장은 브라우저의 localStorage 기반이라 같은 브라우저, 같은 기기에서만 보입니다. 다른 기기로 옮기려면 PDF로 저장해서 공유해주세요.

특정 문제의 답이 틀린 것 같아요

답은 src/data/answers.js에 키-값으로 저장돼 있습니다. 해당 항목을 수정하고 main 브랜치에 커밋하면 다음 빌드부터 반영돼요.

새로운 학년·단원을 추가하고 싶어요

두 곳을 손봐야 합니다. (1) src/config.js의 CATEGORIES와 CHAPTERS에 학년·단원명을 추가, (2) src/data/answers.js에 새 학년의 답안 키를 추가. 이미지는 GitHub의 images/<학년>/ 폴더에 업로드하면 자동으로 보입니다.

손글씨 풀이를 같이 인쇄하고 싶어요

업로드만 하면 됩니다. solutions/<학년>/<번호>.png 경로로 손글씨 풀이 사진을 올려주세요 (예: solutions/09/015.png, 파일명은 015처럼 세 자리). 다음에 해당 문제가 담긴 오답노트를 열면 문제 페이지 다음, 정답지 앞에 풀이 섹션이 자동으로 생기고 거기에 풀이가 문제 이미지와 나란히 배치됩니다. 풀이를 안 올린 문제는 풀이 섹션에 등장하지 않고 본문 문제 페이지에만 보여요.
